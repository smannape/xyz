# ISSPS demo

Demo of the Integrated Subsurface-Surface Planning System. All data is illustrative.

```bash
npm install
npm run dev          # local development
npm run check-data   # assert the dataset is internally consistent
npm run build        # check-data + typecheck + bundle → dist/
npm run preview      # serve dist/ — test this, not the dev server, before a demo
```

Deploy: drag `dist/` onto app.netlify.com/drop, or connect the repo (`netlify.toml` is committed).
Hash routing and `base: './'` mean no redirects are needed and the folder also opens locally.
Fonts are self-hosted in `public/fonts/`; the app makes no runtime network requests.

Until the Command Centre exists, `/` opens the GC-24 ladder at Q2 2027.

## Data

`src/data/*.json` is generated by `scripts/gen-data.mjs` (`npm run gen-data`) and checked
independently by `scripts/check-data.mjs`. The app does no engineering calculation at runtime
beyond the live residual sum in the cascade. Locked specification values are asserted by
`check-data`; do not edit the JSON by hand.
